# Mockups

One directory per tracker `ID`, one subdirectory per version:

```text
visual/mockups/obj103/v1/
visual/mockups/obj103/v2/
visual/mockups/mon12/v1/
```

Each version holds the proposal images and a short `NOTE.md` saying what the
artist was going for. Record the version in the tracker's `Mockup Version`
column and move the row to `REVIEW` when it is ready for the director.

Images are covered by the Git LFS rules in `visual/docs/PIPELINE.md`.
